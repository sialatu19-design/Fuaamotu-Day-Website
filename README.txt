FUA'AMOTU DAY EVENT 2026 WEBSITE AND PROTOTYPE

FILES INCLUDED:
- index.html: Working website prototype (About, Event Video, Schedule and Registration sections).
- wireframes.html: Low-fidelity wireframes for the Home, Event, Schedule and Registration pages.
- fuaamotu.jpg: Website image.
- fuaamotu-event-video.mp4: Local event video.

HOW TO OPEN THE WORKING WEBSITE:
1. Extract this ZIP folder.
2. Keep all files together in the same folder.
3. Double-click index.html to open the website in Chrome or Edge.

HOW TO VIEW THE WIREFRAMES:
1. Open the extracted folder.
2. Double-click wireframes.html.

The registration form is a demonstration prototype. It does not send or store real registrations online.
